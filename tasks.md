# Tasks

*No active task list.*

`tasks.md` is generated by `/plan-to-task` from `plan.md`, and holds two things:

1. **`## DoD Scoreboard – UC<nn>`** — mirrored from the use case spec's
   `## 10. Definition of Done`. The spec is authoritative; this is a scoreboard rebuilt
   each iteration (`loop.playbook.md` § 1).
2. **Phased task blocks** — `RED → GREEN → REFACTOR → review/document → gates`, numbered so
   `/execute-task 1.1` can reference one.

A box is ticked only when a named passing test or an existing file proves it.
"Implemented" is not evidence (`test.definition.md` § 9).

Start with `/spec-create`, `/uc-to-plan` or `/loop-uc` — see `plan.md`.
